# Examples

The full results of the TAREEK example runs (reports, figures and data) are in a separate
repository: **[TAREEK-examples](https://github.com/jalal1/TAREEK-examples)**.

This folder keeps only a small copy of each example: `README.md`, `config_used.json` and
`config.xml`. The web app uses these files for its presets, and the smoke tests load
them. Each README has a link to the full results at the top.
